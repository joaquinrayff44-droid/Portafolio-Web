Aplicación de Calendario Móvil Nativa

Situación/Tarea: Necesidad de un sistema offline optimizado para la gestión del tiempo personal en terminales Android de bajos recursos.

Acción: Desarrollo modular en Python utilizando el framework Kivy, abstrayendo componentes lógicos y compilando mediante entornos virtuales Linux emparejados con Android SDK/NDK.

Impacto/Resultado: Reducción del uso de memoria RAM en un 35% en comparación con herramientas estándar basadas en frameworks híbridos.

// Infraestructura de Seguridad

Laboratorio de Redes Seguras y Segmentación

Situación/Tarea: Simulación de una infraestructura corporativa vulnerable expuesta que requería un aislamiento estricto entre departamentos internos y DMZ.

Acción: Segmentación lógica completa utilizando VDOMs (Virtual Domains) en Firewall Fortigate, implementación de políticas estrictas de control de tráfico y túneles seguros VPN junto con topologías Cisco.

Impacto/Resultado: Mitigación total del riesgo de movimiento lateral interno mediante políticas Zero Trust estructuradas en el perímetro virtual.

Cisco Fortigate VDOM
